# Security policy

## Report a problem in private

Do not open a public issue for a security problem.

Use one of these ways:

- GitHub: "Report a vulnerability" in the Security tab of this repository.
- Email: security@polipan.dev

Please tell us what you found, the version, and steps to repeat it.

## What to expect

- We reply within 3 working days.
- We share a fix plan within 14 days.
- We publish a fix and an advisory. We name you if you want.

## Supported versions

Only the latest release gets security fixes until version 1.0. After that, the latest minor release of the current major version.
