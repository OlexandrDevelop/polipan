# Governance

Polipan is an open source project under the Apache-2.0 license.

## Roles

- **Contributor**: anyone who sends an issue, a pull request or a review.
- **Maintainer**: a contributor who can merge pull requests.

## How decisions are made

- Small changes: one maintainer review is enough.
- Big changes (API, data model, security): open an issue first. At least two maintainers must agree. If there is only one maintainer, that person waits at least 7 days for comments.
- Disagreement: we look for a consensus. If there is none, the maintainers vote. A simple majority wins.

## Becoming a maintainer

A contributor with a steady record of good changes can be invited by the current maintainers. The vote must be unanimous.

## Rules

- No CLA. We use the DCO sign-off (see `CONTRIBUTING.md`).
- No feature is locked behind a paid license.
- We follow the `CODE_OF_CONDUCT.md`.
